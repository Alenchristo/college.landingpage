# college.landingpage
modern, visually appealing, and fully responsive single-page website for a college using HTML, CSS, and JavaScript.

## Vercel Deployment
This project is configured for deployment on Vercel as a static site.

### To deploy
1. Install the Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project folder.
3. When prompted, choose the current directory and accept the defaults.

### Vercel config
- `vercel.json` uses `@vercel/static`
- `index.html` is the entry point
- clean URLs are enabled
